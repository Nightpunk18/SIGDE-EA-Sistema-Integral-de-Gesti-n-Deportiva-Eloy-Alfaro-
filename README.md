# SIGDE-EA-Sistema-Integral-de-Gesti-n-Deportiva-Eloy-Alfaro-
Sistema web de gestión deportiva y administrativa para la Liga Deportiva Barrial «Eloy Alfaro». Proyecto enfocado en la administración de clubes, jugadores, campeonatos, programación de partidos, resultados, tablas de posiciones, sanciones, multas y gestión de usuarios, mediante procesos automatizados y control de información.
